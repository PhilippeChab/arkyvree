# Changelog

## Unreleased

- The characters list's Recently Updated order counts every change to a character, its levels, items, ability scores, languages, modifiers and portrait, and its familiar's, companion's or mount's, not only its details
- A fork starts Private, a campaign invite says it was sent, a class's levels show their base attack bonus as the sheet does ("+6/+1") and 0 spells a day where the SRD does, and a ruleset's search finds a name by a typo rather than by letters spread across words
- Inventory: Add Item and Update wait while the slot's warning stands, and equipping two-handed names everything in the way, a weapon and a shield alike
- D&D 3.5 sheets and PDFs open their spells on a Spells per Day table, a cleric's domain slot and a specialist wizard's school slot shown as "+1" in their class's row
- The characters list opens on the most recently updated character first; the other orders stay in its Sort menu
- D&D 3.5: a feat's "Caster level" prerequisite checks your caster level, not the highest spell level you cast: Craft Wand opens at caster level 5
- Renaming a ruleset's entry (a feat, a spell, a list, an item…) to a name the ruleset already shows is refused, as creating one is, and so are restoring a parent's version and subscribing to an extension that would show a name twice
- Unsubscribing from an extension is refused while it would bring back an entry (a core feat it changes) under a name your fork has given another entry since
- An extension's entry that its author adds or renames to the name of one of your fork's own shows as yours alone in your fork, not twice: what of the book named it uses yours

## 0.5.0 — 2026-05-21

- Character contributors: invite collaborators by email to edit a character and download its PDF
- D&D 3.5 familiars: pick a familiar from race / pick feats, with automatic stat derivation from the master and shared portraits
- D&D 3.5 Ranger Favored Enemy picks, including the level-5+ specialization "+2" bumps, plus auto-routing for prestige class umbrella feats
- Duplicate any ruleset item from its row action, and bulk-create variants of an item from a single dialog

## 0.4.1 — 2026-04-30

- Try-it-now demo accounts: use the app for an hour without signing up
- User avatars and character portraits with image upload

## 0.4.0 — 2026-04-20

- Added Mechanics section to rulesets for documenting base-game mechanics the app doesn't enforce — things like grapple, trip, or bull rush
- Ability score generation methods at character creation (standard array, point buy, rolled)
- Background PDF character sheet generation — get notified when the PDF is ready
- Unified notifications feed replaces the dashboard activity section
- Add Level is now a unified flow — plan one or more levels at once with pooled feat, skill, and spell selections
- Compact PDF character sheet: tighter skills/feats sections, canonical spell ordering, weight summary in inventory, cleaner details header

## 0.3.0 — 2026-04-03

- Added Complete Arcane extension
- Batch level-up wizard for leveling multiple levels at once
- Add and manage custom modifiers directly on the character sheet
- Spell possession modifier system for granting spells via items and characters
- Improved target path browser with tooltips, smarter descriptions, and entity type filtering
- Unmet requirement trees shown on hover for ineligible classes and feats

## 0.2.1 — 2026-03-27

- Added Complete Adventurer extension
- Character languages section with multi-select UI
- Template value picker for modifiers and requirements in the ruleset editor

## 0.2.0 — 2026-03-22

- Sign in with Google
- Notifications for activity across rulesets, campaigns, and characters
- Share character sheets via a public link
- Edit levels and ability scores directly on the character sheet
- Invite contributors to collaborate on rulesets with role-based permissions
- Onboarding walkthrough for new users
- Added Complete Divine and Complete Scoundrel content

## 0.1.0 — 2026-02-27

- Create, publish, and fork rulesets
- Define abilities, races, classes, skills, feats, spells, items, saves, and aptitudes
- Customize entities with properties, requirements, and modifiers
- Fork rulesets, merge changes between forks, and subscribe to extensions
- Create characters with a guided step-by-step wizard
- Level up with class selection, HP, skill points, feats, and spells
- Export character sheets as PDF
- Create campaigns, invite players, and control character visibility
- Track activity across rulesets, characters, and campaigns
- Built-in D&D 3.5e SRD ruleset included
- Install as an app on desktop and mobile
